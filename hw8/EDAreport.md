# 如何理解 IC 設計中的 EDA——以 ccc-eda 的 veryl2chip 實作為例

## 一開始的想法
一開始以為 EDA 只是「畫電路的軟體」。做完 nand2tetris，從 AND、ALU 一路兜到 PC、CPU 之後，整條流程原本被想成：HDL 這一端由簡到繁設計電路，EDA 再把 HDL 變成真正的元件、排版，最後放到電路板上。實際操作 ccc-eda 的 veryl2chip 之後才發現，這個想法要修正兩個詞。

## 需要修正的兩個詞
第一，EDA 不是把元件放到「電路板（PCB）」，而是放到「晶片內部（die）」。第二，電路的功能在 HDL 階段就定案了；後面的步驟不是重新「設計電路」，而是「實體實作」——決定用哪些元件、擺哪裡、怎麼接、來不來得及。

## 用 Blinky 走一遍
在 ccc-eda 的 veryl2chip 線上 IDE 打開「第 1 課 Blinky」。它只是一個每個時脈加一的計數器，把最高位元接到 LED；HDL 只有一句行為：`cnt = cnt + 1`。接著依序看合成階段：

- ①–③ 合成：這句話變成 24 個正反器加一串加法邏輯，也就是閘級網表。
- ④ LUT4：通用閘被對應到 iCE40 真正有的 LUT4 與 DFF。這一步就像 nand2tetris 用 NAND 兜出 XOR，只是自動化。
- ⑤ 布局、⑥ 繞線：把 LUT 擺到晶片格子裡，再用金屬線接起來。這是 nand2tetris 完全沒有的「實體」階段。
- ⑦ 時序：算出關鍵路徑約 29.7 ns、Fmax 約 33.7 MHz。nand2tetris 假設零延遲，但真實電路不能快過最慢的那條路。

| 階段 | 看到的變化 | 產物 |
|---|---|---|
| HDL | 一句 `cnt = cnt + 1` | 行為描述 |
| ①–③ | 變成 DFF 與邏輯閘 | 閘級網表 |
| ④ | 對應到 LUT4／DFF | 目標晶片的元件 |
| ⑤⑥ | 擺位置、拉線 | 晶片上的座標與連線 |
| ⑦ | 算延遲 | 關鍵路徑與 Fmax |

## FPGA 和 ASIC 是兩種不同的實作方式
一開始以為 FPGA 和 ASIC 只是「兩種把元件放進晶片的方式」，後來才發現真正的差別是「晶片是不是事先做好」。

- FPGA：晶片出廠時就做好一大片可重組的邏輯格子（LUT＋可程式開關）。燒進 bitstream，決定這片現成硬體怎麼接，可以重燒、改設計。
- ASIC：沒有現成硬體，交出 GDSII（製造藍圖），由晶圓廠把晶片做出來；放的是標準元件與金屬線，做下去就不能改，改版要重做光罩。

| | FPGA | ASIC |
|---|---|---|
| 晶片 | 通用、已做好 | 為功能客製 |
| 產出 | bitstream | GDSII 光罩 |
| 能不能改 | 可重燒 | 不能，改版要重做光罩 |
| 速度／功耗／面積 | 較差 | 最好 |
| 適合 | 原型、少量、教學 | 量產 |

用比喻來說，FPGA 像用樂高積木組東西，卡榫都現成；ASIC 像開模做專屬零件，開模很貴，但量產後又小又快又省電。

## ASIC 裡面還分 vlib 和 SKY130
這兩個不是第三、第四條路線，而是 ASIC 底下「用哪一套元件庫／製程」的選擇，流程其實是同一套：標準元件 → 列式布局 → CTS → 繞線 → 時序 → 功耗。

- ASIC · vlib：veryl2chip 內建的教學用標準元件庫（列高 4.0 µm、site 0.5 µm，約 130 nm 慢速角），數字比較抽象，適合先看懂流程。
- ASIC · SKY130：真實的 SkyWater 130 nm PDK（`sky130_fd_sc_hd`）。用真實元件與設計規則，會做 DRC，最後能下載可製造的 GDSII。

```
實作方式
├─ FPGA：現成可重組晶片 → bitstream（LUT + 可程式開關）
└─ ASIC：客製晶片 → GDSII（標準元件 + 金屬線）
   ├─ vlib   ：內建教學元件庫
   └─ SKY130 ：真實 SkyWater 130 nm PDK（含 DRC）
```

## 現在對 EDA 的定義
因此現在會這樣定義：EDA 是把 HDL 描述的電路（由 AND、ALU 到 CPU），一層一層轉成目標晶片真正有的元件，在晶片內部完成布局佈線，並用模擬、驗證、時序檢查它對不對、夠不夠快；最後依實作方式產生 bitstream（FPGA）或 GDSII（ASIC）。

## 最大的收穫
最大的收穫是看懂 nand2tetris 停在哪裡：它停在描述與模擬，EDA 真正值錢的是後面的合成、布局佈線、時序與驗證。這次也釐清 FPGA、ASIC、vlib、SKY130 不是四條平行的路，而是「實作方式」和「元件庫」兩層的選擇。以 ccc-eda 的 veryl2chip 把整段流程實際走過一遍，才真的把課本名詞和畫面連起來。
